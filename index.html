About Me

I am a Full-Stack and Mobile Developer dedicated to building scalable web applications, robust backend architectures, and performant cross-platform mobile solutions. Specializing in modern JavaScript, Node.js, and Flutter, I engineer fluid user interfaces backed by clean, maintainable code structures.

My backend expertise focuses on real-time systems and production-grade security integrations. I design REST APIs and socket architectures enforcing OWASP standards, role-based access control (RBAC), WebRTC stream encryption, and parameterized database queries to ensure complete data integrity.

Whether implementing reactive state management with Riverpod and GoRouter or building lightweight DOM engines from scratch, I focus on delivering secure, high-impact software that solves real-world problems.
